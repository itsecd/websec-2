Погода по населённым пунктам

Карта, поиск и прогноз на несколько дней

Как пользоваться

  1. Найдите населённый пункт по названию.
  2. Нажмите точку на карте или карточку в списке.
  3. Вставьте token от Project // Eol и получите графики.

Геопозиция используется только в вашем браузере.

Подсказка

Кликните по точке на карте, чтобы открыть модальное окно с прогнозом. Список слева можно фильтровать по названию, региону и численности.

Что подгружается динамически

Список точек, фильтр поиска, данные прогноза, сводные карточки и графики в модальном окне обновляются без перезагрузки страницы.

Формат данных

Проект ожидает JSON с объектами вида: name, region, lat, lon, population. Скрипт в папке scripts умеет собирать такой файл из CSV.
