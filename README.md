# Лабораторная работа №2

## Вариант 2. Аналог Прибывалки для электричек

Веб-приложение на Next.js для просмотра расписания пригородных поездов через API Яндекс.Расписаний.

### Реализованные возможности

- поиск ЖД-станции по названию
- поиск ближайших станций по карте
- просмотр расписания всех проходящих поездов через выбранную станцию
- просмотр расписания поездов между двумя станциями
- адаптация интерфейса под мобильные устройства

### Используемые технологии

- Next.js
- TypeScript
- Material UI
- Leaflet
- API Яндекс.Расписаний

## Запуск проекта

### 1. Установить зависимости

```bash
npm install
```

### 2. Создать файл переменных окружения

Создать файл `.env.local` в корне проекта.

Пример содержимого:

```env
YANDEX_RASP_API_KEY=your_api_key
NEXT_PUBLIC_DEFAULT_MAP_LAT=53.195873
NEXT_PUBLIC_DEFAULT_MAP_LNG=50.100193
NEXT_PUBLIC_DEFAULT_MAP_ZOOM=11
```

### 3. Подготовить локальный индекс станций

Поиск по названию работает через локальный индекс станций. Перед первым запуском его нужно собрать.

Linux/macOS:

```bash
export $(grep -v '^#' .env.local | xargs)
npm run prepare:stations
```

Windows PowerShell:

```powershell
$env:YANDEX_RASP_API_KEY="your_api_key"
npm run prepare:stations
```

После выполнения команды будет создан файл:

```text
data/station-index.json
```

### 4. Запустить приложение

```bash
npm run dev
```

## Структура проекта

- `app/` — страницы приложения и API-роуты
- `components/` — клиентские компоненты интерфейса
- `lib/` — типы, работа с параметрами и запросами к API
- `scripts/` — скрипт подготовки локального индекса станций
- `data/` — сгенерированный индекс станций

## Особенности реализации

- серверная часть выполняет запросы к API Яндекс.Расписаний
- клиентские компоненты отвечают за интерактивность интерфейса
- поиск по карте выполняется через запрос ближайших станций
- поиск по названию выполняется по локальному индексу станций
