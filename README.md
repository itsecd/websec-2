# Веб-приложение "Прогноз погоды с картой"

## Задание
Лабораторная работа №2 по безопасности веб-приложений (Вариант 3).  
Требуется реализовать одностраничный сайт с картой, на которой можно выбрать населенный пункт и получить прогноз погоды на несколько дней с графиками температуры, ветра и осадков.

## Выполненные требования
- Верстка HTML ~250 тегов.
- Адаптивный CSS (мобильная версия).
- Использование jQuery (AJAX-запросы к API, динамическое создание модальных окон, обновление DOM).
- Динамическая подгрузка контента: прогноз погоды грузится по клику.
- Динамическое изменение DOM и CSSOM (графики ChartsJS, смена вкладок, попапы).
- Интерактивная карта Leaflet с 1000 маркеров (размер отражает население).
- Поиск города по названию (геокодинг Open-Meteo).
- Графики Chart.js (три независимых графика).
- Источник прогноза — Open-Meteo (замена ProjectEOL).
- Координаты городов — 1000 крупнейших населенных пунктов РФ (из открытых данных).

## Запуск
1. Скачать все файлы.
2. Открыть `index.html` в современном браузере (лучше через Live Server для корректной работы карты).
3. Разрешить доступ к геолокации не требуется, все API работают без ключей.

## Используемые API
- Open-Meteo Forecast: `https://api.open-meteo.com/v1/forecast`
- Open-Meteo Geocoding: `https://geocoding-api.open-meteo.com/v1/search`
- Тайлы карты: CartoDB + OpenStreetMap

## Примечания
Проект полностью клиентский, API-ключи не нужны.
get_settlements.py используется однократно для получения списка городов (settlements.json) из .csv выгрузки с сайта tochno.st
