# Карта населённых пунктов и прогноз погоды

Проект состоит из следующих частей:

* `index.html` — страница с картой, поиском, панелью статистики и модальным окном графиков
* `style.css` — стили и адаптивная верстка
* `app.js` — логика карты, поиска, загрузки прогноза и построения графиков
* `data/settlements.json` — набор точек для карты (генерируется из CSV)
* `scripts/build-data.js` — скрипт конвертации CSV → JSON
* `server.js` — простой прокси-сервер для корректного запроса к API

---

## 🚀 Запуск проекта

1. Установите Node.js (если ещё не установлен)

2. Подготовьте CSV файл с данными населённых пунктов
   (должен содержать: название, регион, широту, долготу, население)

3. Сгенерируйте JSON:

```bash
node scripts/build-data.js input.csv data/settlements.json
```

4. Запустите прокси-сервер
```bash
node server.js
```

5. Для работы необходим HTTP-сервер:

```bash
python -m http.server 8000  
```

6. Затем откройте http://localhost:8000 в браузере.
---

## ⚠️ Важно про данные

Скрипт автоматически:

* определяет нужные колонки по названиям
* очищает и нормализует данные
* отфильтровывает некорректные координаты:
* оставляет 1000 крупнейших населённых пунктов по населению

Если в CSV есть некорректные или пустые строки — они будут пропущены.

---

## 🌍 Функциональность

Интерфейс поддерживает:

* отображение населённых пунктов на карте
* поиск по названию
* клик по точке для получения прогноза
* отображение графиков:

  * температура
  * осадки
  * ветер

---

## 🔑 Настройка API

Для получения прогноза погоды требуется токен.

1. Получите token от Project // Eol
2. Вставьте его в интерфейсе
3. Он автоматически сохранится в `localStorage`
