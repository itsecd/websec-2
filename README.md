# WebSec 2. Расписания

Выполнен вариант 1: аналог раздела расписания Самарского университета.

Запуск:

```text
start.bat
```

Или вручную:

```bash
npm install
npm start
```

Локальный адрес:

```text
http://localhost:3000
```

Реализовано:

- серверная часть на Express;
- справочник групп и преподавателей через серверный POST к `https://ssau.ru/rasp/search`;
- расписание группы или преподавателя через серверную загрузку публичной страницы `ssau.ru/rasp`;
- локальные JSON-API `/api/search` и `/api/schedule`;
- клиентская динамическая подгрузка через jQuery;
- выбор учебной недели, предыдущая/следующая неделя;
- адаптивная табличная и мобильная верстка.
