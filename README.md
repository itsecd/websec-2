## Установка и запуск

### 1. Клонирование репозитория

git clone <url-репозитория>
cd websec-2

### 2. Создание виртуального окружения

python -m venv venv
venv\Scripts\activate

### 3. Установка зависимостей

pip install -r requirements.txt

### 4. Запуск сервера

python run.py

### 5. Открыть в браузере

http://localhost:8000
