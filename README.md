## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <url-репозитория>
cd websec-2
```

### 2. Создание виртуального окружения
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск сервера
```bash
python run.py
```

### 5. Открыть в браузере

http://localhost:8000
